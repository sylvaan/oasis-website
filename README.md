# 🌲 The Wild Oasis

A simple booking website for a luxury cabin resort. Built with **Next.js 15** and **React 19**.

> Live Demo can be accessed here [https://sylvaan-oasis-website.vercel.app/](https://sylvaan-oasis-website.vercel.app/)

---

## Features

- **Browse Cabins**: View all available cabins for rent.
- **Filter by Capacity**: Filter cabins based on total guests.
- **Google Login**: Guest authentication using Google (**NextAuth.js**).
- **Reservations**: Guests can book cabins and see reserved dates on the calendar.
- **Guest Dashboard**: A dedicated page for guests to manage their profile and view their bookings.
- **Edit/Delete Stays**: Guests can modify (guest count/notes) or cancel their upcoming reservations.

## Tech Stack

- **Core**: [Next.js 15](https://nextjs.org/), [React 19](https://react.dev/)
- **Backend**: [Supabase](https://supabase.com/)
- **Auth**: [NextAuth.js v5](https://next-auth.js.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
